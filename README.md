# Foto2List
Compile a checklist of plants based on the renamed photos (Chinese only). Note: Python code and summary below were generated by Deepseek

This Python script is a GUI-based tool (Tkinter) that processes photos to extract EXIF metadata and match species information against a reference checklist. It allows users to select a photo folder and specify an output Excel filename. For each image, it reads capture date/time, GPS coordinates (latitude, longitude, altitude), camera make/model, and image dimensions. It then parses the filename to extract Chinese names or Latin binomials. Using a default Excel checklist — "Checklist of plants of China 2026.xlsx" — which must contain a column named "种中文名" (Chinese species name), the script matches extracted names to species records. If the column is missing, it raises an error and prompts the user to create a proper template. Matched data includes canonical name, genus, family, distribution, and other selected columns. All information is compiled into an Excel sheet with one row per photo. The tool automatically searches for the checklist in common locations, offers a template generator, and includes progress logging. It runs in a background thread to keep the interface responsive, and gracefully handles missing files or permissions.
